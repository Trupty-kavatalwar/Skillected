1 What is JavaScript? Explain its benefits.
Explanation (EN)
JavaScript is a lightweight, interpreted programming language used to make web pages interactive. It runs directly in the browser and can also run on servers using Node.js. Benefits: adds interactivity (animations, validation, dynamic content), runs on client-side so pages respond instantly without reloading, works with HTML/CSS on every browser, and has a huge ecosystem of libraries and frameworks (React, Node.js, etc).
स्पष्टीकरण (MR)
JavaScript ही एक हलकी (lightweight), इंटरप्रिटेड प्रोग्रामिंग भाषा आहे जी वेब पेजेस इंटरॅक्टिव्ह बनवण्यासाठी वापरली जाते. ती ब्राउझरमध्ये थेट चालते आणि Node.js च्या मदतीने सर्व्हरवरही चालू शकते. फायदे: पेज इंटरॅक्टिव्ह बनते (अ‍ॅनिमेशन, व्हॅलिडेशन, डायनॅमिक कंटेंट), क्लायंट-साइडवर चालते त्यामुळे पेज रीलोड न करता त्वरित प्रतिसाद मिळतो, HTML/CSS सोबत सर्व ब्राउझरवर काम करते, आणि React, Node.js सारख्या मोठ्या लायब्ररी व फ्रेमवर्क्सचा वापर करता येतो.
Code
console.log("JavaScript makes web pages interactive!");
// It runs in the browser without needing to reload the page
document.title = "Hello from JavaScript";
Expected Output
JavaScript makes web pages interactive!
2 Differentiate between Internal JavaScript and External JavaScript.
Explanation (EN)
Internal JavaScript is written directly inside the HTML file using a <script> tag, usually within <head> or <body>. External JavaScript is written in a separate .js file and linked to the HTML using the src attribute. External JS is preferred for larger projects because it keeps code organized, reusable across pages, and easier to maintain/cache.
स्पष्टीकरण (MR)
Internal JavaScript म्हणजे HTML फाइलमध्येच <script> टॅगच्या आत लिहिलेला कोड, जो साधारणपणे <head> किंवा <body> मध्ये असतो. External JavaScript म्हणजे वेगळ्या .js फाइलमध्ये लिहिलेला कोड जो src attribute वापरून HTML शी जोडला जातो. मोठ्या प्रोजेक्ट्ससाठी External JS चांगले असते कारण त्यामुळे कोड व्यवस्थित राहतो, अनेक पेजेसवर पुन्हा वापरता येतो आणि मेंटेन/कॅश करणे सोपे जाते.
Code
<!-- Internal JavaScript -->
<script>
  console.log("This is internal JS");
</script>

<!-- External JavaScript -->
<script src="script.js"></script>
Expected Output
This is internal JS (External JS output depends on script.js contents)

4 Explain var, let, and const with examples.
Explanation (EN)
var is function-scoped and can be redeclared/updated; it is hoisted and initialized as undefined. let is block-scoped, can be updated but not redeclared in the same scope. const is block-scoped and cannot be updated or redeclared — it must be initialized at declaration and used for values that won't change.
स्पष्टीकरण (MR)
var हे function-scoped असते आणि पुन्हा declare/update करता येते; ते hoist होते आणि undefined म्हणून initialize होते. let हे block-scoped असते, ते update करता येते पण त्याच scope मध्ये पुन्हा declare करता येत नाही. const हे block-scoped असते आणि त्याला update किंवा पुन्हा declare करता येत नाही — ते declare करतानाच value द्यावी लागते आणि न बदलणाऱ्या value साठी वापरले जाते.
Code
var a = 10;
a = 20; // allowed

let b = 30;
b = 40; // allowed, but cannot redeclare with let in same scope

const c = 50;
// c = 60; // Error: Assignment to constant variable

console.log(a, b, c);
Expected Output
20 40 50
5 What is Variable Hoisting in JavaScript?
Explanation (EN)
Hoisting is JavaScript's default behavior of moving declarations to the top of their scope before code execution. var declarations are hoisted and initialized as undefined, so they can be referenced before their line without an error (but their value will be undefined). let and const are also hoisted but stay in a 'temporal dead zone' — accessing them before declaration throws an error.
स्पष्टीकरण (MR)
Hoisting म्हणजे JavaScript कोड execute होण्यापूर्वी variable आणि function च्या declarations आपोआप त्यांच्या scope च्या सुरुवातीला नेण्याची डिफॉल्ट प्रक्रिया. var declarations hoist होतात आणि undefined म्हणून initialize होतात, त्यामुळे त्यांना ओळीच्या आधी वापरले तरी error येत नाही (पण value undefined असते). let आणि const सुद्धा hoist होतात पण ते 'temporal dead zone' मध्ये राहतात — declaration आधी वापरल्यास error येतो.
Code
console.log(x); // undefined (hoisted)
var x = 5;

console.log(y); // ReferenceError
let y = 10;
Expected Output
undefined Uncaught ReferenceError: Cannot access 'y' before initialization

11 Explain Arrays in JavaScript with examples.
Explanation (EN)
An array is an ordered collection of values, which can be of any type, stored under a single variable name and accessed by index (starting from 0). Arrays are resizable and come with many built-in methods.
स्पष्टीकरण (MR)
Array म्हणजे कोणत्याही प्रकारच्या values चा क्रमबद्ध संग्रह, जो एका variable नावाखाली साठवला जातो आणि index (0 पासून सुरू होणारा) वापरून ऍक्सेस केला जातो. Arrays चा आकार बदलता येतो आणि त्यात अनेक built-in methods असतात.

12 Write a program demonstrating push(), pop(), shift(), and unshift().
Explanation (EN)
push() adds an element to the end, pop() removes the last element, shift() removes the first element, and unshift() adds an element to the beginning of the array.
स्पष्टीकरण (MR)
push() हे array च्या शेवटी नवीन element जोडते, pop() शेवटचा element काढते, shift() पहिला element काढते, आणि unshift() array च्या सुरुवातीला नवीन element जोडते.
Code
let arr = [2, 3, 4];

arr.push(5);      // [2,3,4,5]
arr.pop();         // [2,3,4]
arr.unshift(1);    // [1,2,3,4]
arr.shift();       // [2,3,4]

console.log(arr);
Expected Output
[2, 3, 4]

07 Assignment 2 — Links, Marquee, Bookmarks & Flexbox
Theory Questions (1-10)
1 What is the <a> (anchor) tag in HTML? Explain its syntax and uses.
Explanation (EN)
The <a> tag defines a hyperlink used to navigate from one page to another, to a section on the same page, or to open emails/files. Its main attribute is href, which holds the destination URL. Syntax: <a href="url">link text</a>.
स्पष्टीकरण (MR)
<a> टॅग हा हायपरलिंक तयार करण्यासाठी वापरला जातो — एका पेजवरून दुसऱ्या पेजवर, त्याच पेजवरील एखाद्या सेक्शनवर, किंवा ईमेल/फाइल उघडण्यासाठी. त्याचा मुख्य attribute href असतो, ज्यात destination URL दिलेला असतो. Syntax: <a href="url">link text</a>.
Code
<a href="https://example.com">Visit Example</a>
Expected Output
Visit Example (clickable link navigating to https://example.com)
2 Explain the different types of hyperlinks in HTML with examples.
Explanation (EN)
There are mainly three types: (1) Internal link — links to another page within the same website. (2) External link — links to a page on a different website. (3) Same-page (bookmark) link — links to a section within the same page using an id.
स्पष्टीकरण (MR)
मुख्यतः तीन प्रकार असतात: (1) Internal link — त्याच वेबसाइटमधील दुसऱ्या पेजला जोडणारी लिंक. (2) External link — वेगळ्या वेबसाइटच्या पेजला जोडणारी लिंक. (3) Same-page (bookmark) link — id वापरून त्याच पेजमधील एका सेक्शनला जोडणारी लिंक.
Code
<a href="about.html">Internal Link</a>
<a href="https://google.com">External Link</a>
<a href="#section2">Bookmark Link</a>
Expected Output
Internal Link | External Link | Bookmark Link (three separate clickable links)
3 What is the target attribute in HTML? Explain its types (_self, _blank, _parent, _top).
Explanation (EN)
The target attribute controls where a linked page opens. _self (default) opens in the same tab/frame. _blank opens in a new tab/window. _parent opens in the parent frame. _top opens in the full body of the window, breaking out of all frames.
स्पष्टीकरण (MR)
target attribute हे linked page कुठे उघडेल हे ठरवते. _self (डीफॉल्ट) तोच tab/frame मध्ये उघडते. _blank नवीन tab/window मध्ये उघडते. _parent हे parent frame मध्ये उघडते. _top हे सर्व frames मधून बाहेर पडून पूर्ण window मध्ये उघडते.
Code
<a href="page.html" target="_self">Same Tab</a>
<a href="page.html" target="_blank">New Tab</a>
<a href="page.html" target="_parent">Parent Frame</a>
<a href="page.html" target="_top">Top Window</a>
Expected Output
Four links, each opening page.html in a different context as described
4 What is URL path in HTML? Explain absolute URL and relative URL with examples.
Explanation (EN)
A URL path tells the browser where a resource is located. An absolute URL includes the full address (protocol + domain + path), e.g. https://site.com/images/pic.jpg, and works regardless of the current page location. A relative URL is based on the current page's location, e.g. images/pic.jpg, and is shorter but only works within the same site structure.
स्पष्टीकरण (MR)
URL path म्हणजे resource कुठे आहे हे ब्राउझरला सांगणारा पत्ता. Absolute URL मध्ये पूर्ण पत्ता असतो (protocol + domain + path), उदा. https://site.com/images/pic.jpg, आणि सध्याच्या पेजची लोकेशन काहीही असो तरी तो काम करतो. Relative URL हा सध्याच्या पेजच्या लोकेशनवर आधारित असतो, उदा. images/pic.jpg, तो लहान असतो पण फक्त त्याच साइट स्ट्रक्चरमध्ये काम करतो.
Code
<!-- Absolute URL -->
<img src="https://example.com/images/logo.png">

<!-- Relative URL -->
<img src="images/logo.png">
Expected Output
Both display the logo image; absolute works from anywhere, relative works only within the site's own folder structure
5 Differentiate between internal link and external link.
Explanation (EN)
An internal link points to another page within the same website/domain (e.g. href="contact.html"), used for site navigation. An external link points to a page on a completely different website/domain (e.g. href="https://wikipedia.org"), usually used to reference outside resources, and is often opened in a new tab.
स्पष्टीकरण (MR)
Internal link ही त्याच वेबसाइट/डोमेनमधील दुसऱ्या पेजला जोडते (उदा. href="contact.html"), ती साइटच्या navigation साठी वापरली जाते. External link ही पूर्णपणे वेगळ्या वेबसाइट/डोमेनच्या पेजला जोडते (उदा. href="https://wikipedia.org"), ती बाहेरील संदर्भासाठी वापरली जाते आणि सहसा नवीन tab मध्ये उघडली जाते.
Code
<a href="contact.html">Internal Link</a>
<a href="https://wikipedia.org" target="_blank">External Link</a>
Expected Output
Internal Link (stays on same site) | External Link (opens Wikipedia in new tab)

1 What is HTML? Explain its basic structure.
Explanation (EN)

9 Explain different CSS color formats: HEX, RGB, RGBA, HSL.
Explanation (EN)
HEX uses a 6-digit hexadecimal code (#RRGGBB). RGB uses red, green, blue values 0-255, e.g. rgb(255,0,0). RGBA adds an alpha (opacity) value, e.g. rgba(255,0,0,0.5). HSL defines color by hue (0-360), saturation, and lightness percentages, e.g. hsl(0,100%,50%).
स्पष्टीकरण (MR)
HEX 6-अंकी hexadecimal कोड वापरते (#RRGGBB). RGB मध्ये red, green, blue values 0-255 दरम्यान असतात, उदा. rgb(255,0,0). RGBA मध्ये अतिरिक्त alpha (opacity) value असते, उदा. rgba(255,0,0,0.5). HSL रंग hue (0-360), saturation, आणि lightness टक्केवारीने ठरवते, उदा. hsl(0,100%,50%).
Code
<p style="color:#ff0000;">HEX Red</p>
<p style="color:rgb(255,0,0);">RGB Red</p>
<p style="color:rgba(255,0,0,0.5);">RGBA Red (transparent)</p>
<p style="color:hsl(0,100%,50%);">HSL Red</p>
Expected Output
Four lines of red text, the RGBA one appearing semi-transparent
10 Differentiate between semantic and non-semantic tags with examples.
Explanation (EN)
Semantic tags describe their content's meaning, e.g. <header>, <nav>, <article>, <footer>. Non-semantic tags like <div> and <span> are generic containers with no inherent meaning — they only group content for styling/scripting purposes.
स्पष्टीकरण (MR)
Semantic tags त्यांच्या कंटेंटचा अर्थ सांगतात, उदा. <header>, <nav>, <article>, <footer>. Non-semantic tags जसे <div> आणि <span> हे साधे generic containers असतात ज्यांना स्वतःचा अर्थ नसतो — ते फक्त styling/scripting साठी कंटेंट group करतात.
Code
<!-- Semantic -->
<article>This is an article</article>

<!-- Non-semantic -->
<div>This is a generic div</div>
Expected Output
Both display their text; only the <article> conveys meaning to browsers/assistive tech
